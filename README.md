# SimonLight
Memory game

Team members:
- Jonny Ring
- Tom Min
- Nicholas Avikainen

Description of project:
Problem:  People recovering from the side effects of strokes may have reaction and memory problems. Medical professionals need a way to assess the current state of a patient to see if they have any side effects related to cognition that need attention.

Solution: 
Our solution to this problem is a user-friendly device that uses LED lights and corresponding colored buttons to assess memory and reaction time. An accompanying HTML-based website will track patients' scores and allow test proctors to adjust difficulty levels and select different testing modes, including easy, medium, hard, and incremental. Cloud connectivity will enable real-time data collection and score tracking, allowing healthcare professionals to compare results across multiple testing sessions and identify potential changes in cognitive performance.
The device will be controlled through the website, where test proctors can initiate assessments and configure testing settings. Once the test begins, the patient will be prompted to start after an initial sequence of flashing lights. The LED lights will then illuminate in a specific color sequence, which the patient must memorize and reproduce by pressing the corresponding colored buttons. As the test progresses, the sequences will become increasingly longer until the patient can no longer correctly recall them. Once an incorrect sequence is entered, the assessment will end, and the results will be recorded.
Stretch: We also plan on developing an algorithm that creates levels with a different sequence each time if the player wants a surprise level, since we would imagine that it would get rather boring after a while if it was always the same levels played over and over again. 
To incorporate reaction-time testing into the memory assessment, the patient will be required to wait for an audible buzzer before reproducing the color sequence. The device will measure the time between the buzzer and the patient's first button press, providing an additional measurement of their reaction time alongside their memory performance.
